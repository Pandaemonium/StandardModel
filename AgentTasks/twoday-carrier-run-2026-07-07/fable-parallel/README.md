# Fable parallel deep-work kit (2026-07-07)

Purpose: maximal use of Fable-5 in its remaining availability window - ten
independent hard questions, each runnable in its own window, each aimed at
program-defining stakes.

## How to run a window

1. Paste `00-PROJECT-INTRO.md` in full (it is self-contained; Fable has no repo
   access).
2. Paste ONE question file below it.
3. Nothing else is needed; each question restates its own local setup.

Keep prompts as-is (plain math/physics language; the intro carries the honesty
rails so answers come back claim-graded).

## Where answers go

Canonical results location (as actually used): `AgentTasks/fable_parallel/`
at the repository root - Q01-Q03 landed there 2026-07-07 and are integrated
(charter, synthesis rev 2, thread board, queue). Save further answers in the
same place as `QXX_answer.md`. The executor agents will then: cross-review each memo
against the four over-claim modes, extract the formalization ladders into
`THREAD_BOARD.md` threads, queue kernel targets to Aristotle, and reconcile
disagreements between memos (especially Q1 vs Q8 on the quotient, and Q2 vs Q9 on
the boundary functional) in `FABLE_QUEUE.md`.

## Design notes

- Every question demands verdict-first answers, counterexamples in explicit small
  dimensions, exact literature, and a finite formalization ladder - so even a
  partially wrong memo yields kernel targets.
- Q1/Q2/Q6/Q8 are load-bearing for the current run's threads; Q3/Q4/Q5/Q7/Q9/Q10
  set the next program horizon ("unification-grade": gravity + SM content +
  generations + values + entropy + dimension from one finite structure).
- The intro's section 5 keeps Fable honest about what is OPEN, so memos cannot
  silently assume the positivity crux or the glue witness.

# DAY_<n>_REPORT template (max ~40 lines; one agent drafts, other reviews; alternate)

## 1. Delta summary (5 lines max)

What landed today, in plain sentences.

## 2. Theorems landed

Name, file, verification command ACTUALLY RUN, axiom footprint.

## 3. Aristotle registry delta

Submitted / completed / harvested / integrated / failed-parked, with
project ids. Confirm harvest-first was respected.

## 4. Board state

Tasks moved (id: old -> new status). Claims held overnight. Integration
debt (harvested-not-integrated and why).

## 5. Decisions and reviews

Threads opened/resolved; verdicts; disagreements and how settled
(math / Aristotle tiebreak / parked).

## 6. Build and hygiene

Aggregate GateYM build result (job count), full `lake build` if run,
oracle status, pre-commit status. Exact commands.

## 7. Honest negatives

Refuted statements, failed jobs, false starts, reverted commits - with
what each one redirects.

## 8. Tomorrow's plan (3 items max)

Priority-ordered, referencing task ids; note any replan proposal for the
day-start `replan:` thread.

## Question

Which of two order/count architectures has a feasible route through the flat
G2 concentration gate?

- **N:** the compact project-sign Benincasa-Dowker operator, averaged over an
  order-derived protected region of one graph;
- **L:** a clean-room project-sign version of the Boguna-Krioukov local
  temporal/spatial distance-neighborhood operator.

This stage compares operator architectures. It does not select dimension or
absolute scale from a bare graph, open curvature, or claim a continuum theorem.

## Phase A: deterministic and implementation controls

No random held-out benchmark may be opened until both implementations pass:

1. constants are annihilated by the normalized operator used in the corrected
   pairing;
2. the source-to-project sign is explicit and gives `(+---)` quadratic response;
3. affine leakage is reported separately in time and each spatial direction;
4. temporal and spatial quadratic controls are nonzero and have the intended
   relative sign;
5. relabeling covariance and support locality pass exactly;
6. every supplied continuum coordinate or distance is tagged as oracle input;
7. runtime and neighborhood/event counts are recorded.

Branch N must additionally reproduce the A41c point-row target before regional
averaging. Branch L must reproduce the paper's coordinate-oracle temporal and
spatial finite-difference formulas in `1+1` and `2+1` before any intrinsic
distance estimate is substituted.

## Phase B: finite-sprinkling comparison

After Phase A, freeze one development and one held-out density schedule common
to both branches. Use the same compact flat diamond, marked/protected target
region, polynomial field family, and realization for every comparison.
Required fields are

```text
1, t, x1, t^2, x1^2, t*x1, t^3, t*x1^2
```

and the `3+1` run must repeat the spatial quadratic and affine controls in all
three axes. Coordinate values may evaluate oracle fields but may not select
events, neighborhoods, weights, or scales in the intrinsic score.

## Branch-specific obligations

### N: compact nonlocal regional observable

- Select pivots using only count depth inside the marked diamond.
- Reuse one graph and its random taper across all pivots.
- Report the full empirical covariance matrix of pivot rows and of their
  weighted average.
- Compare empirical average variance with the independent-row estimate and
  the exact positive diagonal single-row contribution.
- Treat overlap covariance as part of the result, never as an error bar to be
  omitted.

### L: intrinsic local challenger

- Use order-derived longest-chain temporal distances and a documented
  order-derived spacelike-distance estimator.
- Freeze all event selectors, neighborhood sizes, and temporal/spatial balance
  constants before held-out data.
- Report coordinate-oracle, temporal-distance-only, and fully intrinsic scores
  separately so distance-estimator noise is identifiable.
- Audit both the symmetric construction and a separately defined retarded
  variant; do not infer one from the other.

## Common scorecard

For each density and branch report:

- constant and affine leakage;
- all quadratic responses and corrected-pairing matrix;
- rank, signature, conformal error, and count-volume mismatch;
- principal-symbol ratio and product-response error;
- per-realization and ensemble errors;
- covariance/effective-sample-size diagnostics;
- runtime, memory, and selected-neighborhood counts.

## Gate and branching rule

A branch is **retained** only if, on every held-out profile and dimension it
claims to solve:

1. the corrected pairing has rank four and signature `(1,3,0)` in at least
   `75%` of `3+1` realizations;
2. held-out ensemble conformal error is below `0.20`;
3. median affine leakage relative to the smaller nonzero quadratic response is
   below `0.20`;
4. quadratic and conformal errors improve by at least `15%` over the frozen
   density step;
5. no oracle-selected event, neighborhood, distance, or scale enters the
   intrinsic score;
6. the reported covariance model is consistent with empirical variance to
   within a factor of three.

If neither branch passes, G2 remains at operator reconstruction and no
curvature experiment follows. If only N passes, retain compact retarded
regional reconstruction and begin an analytic overlap-covariance bound. If
only L passes, require a curved principal-symbol and retardedness audit before
promotion. If both pass, prefer neither by fit alone: compare locality,
retardedness, curved response, and computational scaling under a separately
frozen successor.

## Protocol integrity

The exact development and held-out seeds, densities, neighborhood schedules,
and profile parameters will be appended before either branch opens random
data. They must be common wherever the dimensional construction permits.
Failure to implement one branch is a development failure, not evidence that
the other branch passes.

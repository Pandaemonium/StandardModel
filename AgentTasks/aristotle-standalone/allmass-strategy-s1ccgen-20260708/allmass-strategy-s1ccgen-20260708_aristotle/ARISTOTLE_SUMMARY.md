**Answer to the three-part task**

1. **General reduction, stated.** For a scalar-metric single-edge carrier `H = ℂ^ι` (ι the full carrier index — a product type like Clifford×color) with Hermitian closure form `J = J Q_C`, a diagonal ±1 closure grading `b = diagonal d` satisfying the full-carrier anticonjugation `b·J·b = -J` (property (A), which mentions only the pair `(J,b)`, never `Q_G`), and *any* coset-representative map `r : κ → ι`: the compressed physical-sector form `B = J.submatrix r r` is balanced, `n₊ = n₋`. `Q_G` enters only by selecting `r`, and balance holds for every `r`.

2. **Proof — it IS general.** The balance engine needs only that `B` is Hermitian and `(-B).charpoly = B.charpoly`; the latter follows from any congruence anticonjugation `S⁻¹BS = -B`. The key lemma `compression_inherits_anticonj` shows a *diagonal* grading's anticonjugation is inherited by *every* submatrix compression by one line of entrywise algebra: `(diagonal(d∘r)·B·diagonal(d∘r))_{ij} = d(r i)·J_{r i,r j}·d(r j) = (b·J·b)_{r i,r j} = -B_{ij}`. Nothing about `r`/`Q_G` is used, so `b`-anticonjugation survives compression structurally. A general (non-aligned) Hermitian `G` reduces to this shape by a color-leg unitary that diagonalizes `G` while fixing `b = σz⊗1` (they commute) and preserving (A) — so the witness's coordinate alignment is presentation, not content. The only `Q_G`-dependence is `σz c₁ σz = -c₁` (the null covector is σz-odd), giving `b Q_G = -Q_G b`, hence `b` preserves `ker Q_G`/`range Q_G`; this holds for the whole scalar-metric class.

3. **No-go honesty.** Within the scalar-metric class positivity survives only vacuously: `n₊ = n₋` forces indefiniteness unless the sector is trivial (`K̄ = 0`); on any nondegenerate nonempty sector `compression_has_neg_eigenvalue` produces a negative direction, so the form is never positive semidefinite. The honest boundary is exactly kill condition K-A: a genuinely *soldered* (non-factorized) `Q_G` mixing the Clifford and color legs breaks `b`-invariance, so `b` need not descend to `V'/N`, (A) need not survive, and the theorem does not apply. The general reduction is thus a theorem precisely on the scalar-metric (factorized, σz-odd null covector) class and can fail only outside it.

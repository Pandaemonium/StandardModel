## Model

The soldering channel `E` is added as a coupling on the on-site block. In the real
matrix algebra generated by `I`, `J = !![0,-1;1,0]` (`J² = -I`, chiral turn) and
`S = !![1,0;0,-1]` (`S² = I`, soldering / grading):

- on-site block `A = lam·I + E·S`,
- coupling block `B = kap·I + tau·J`, conjugate `B̄ = kap·I - tau·J`,
- decimated middle site `H = lam·I + E·S`, with `H⁻¹ = (1/d)(lam·I - E·S)`, `d = lam² - E²`.

The two-site Schur complement gives

- new on-site `A' = A - (1/d)(B·(lam I - E S)·B̄ + B̄·(lam I - E S)·B)`,
- new coupling `B' = -(1/d)·B·(lam I - E S)·B`.

The two grounding ring identities are proved on concrete rational `2×2` matrices:

- `coupling_numerator`: `B·(lam I - E S)·B = lam(kap²-tau²)·I + 2·lam·kap·tau·J - E(kap²+tau²)·S`,
- `onsite_numerator`: `B·(lam I - E S)·B̄ + B̄·(lam I - E S)·B = 2·lam(kap²+tau²)·I - 2·E(kap²-tau²)·S`.

The on-site block closes **exactly** in `span{I,S}`, yielding `lam'` and `E'`. Reading the
`I`/`J` components of `B'` gives `kap'`/`tau'`. (The coupling acquires an admixture
`-E(kap²+tau²)/d · S`; it vanishes on the invariant subspace `E = 0` and is not retained
among the four physical couplings — this is the standard four-coupling truncation.)

## R4 (closed rational four-coupling decimation), `d = lam² - E²`

```
lam' = lam - 2·lam·(kap²+tau²)/d
kap' = -lam·(kap²-tau²)/d
tau' = -2·lam·kap·tau/d
E'   = E + 2·E·(kap²-tau²)/d
```

- **`R4_closed_form`**: `R4(lam,kap,tau,0) = (R3(lam,kap,tau), 0)` for `lam ≠ 0`; the
  soldering-free subspace `E = 0` is invariant and reproduces the landed 3-channel map
  `R3` (the free-Dirac chiral square `z' = -z²/lam`, `z = kap + i·tau`).

## Critical Jacobian at the fixed point `(1,1,0,0)`

- **`critical_jacobian`**: every entry of the `4×4` matrix `DR4` is the corresponding
  partial derivative of `R4`, proved column by column via `HasDerivAt`:

```
       lam  kap  tau   E
lam' [  3   -4    0    0 ]
kap' [  1   -2    0    0 ]
tau' [  0    0   -2    0 ]
E'   [  0    0    0    3 ]
```

The upper-left `3×3` block is exactly the 3-channel Jacobian `DR3` (eigenvalues `2, -1, -2`).
The `E`-row and `E`-column decouple at linear order because every `E`-dependence enters
through `d = lam² - E²`, whose `E`-derivative vanishes at `E = 0`.

- **`rg_eigenvalues`**: the roots are exactly `{2, −1, −2, 3}`. The first three reproduce

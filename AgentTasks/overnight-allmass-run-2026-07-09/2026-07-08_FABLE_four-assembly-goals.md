## Run hygiene (the S1-CC lesson, made policy)

The presentation-existence saga — where an autonomous pass proved a *vacuously degenerate* version (Hermitian nilpotent ⇒ `Q_G = 0`) and it took two review rounds to catch — should be encoded into this run's job specs, because all four goals are existential-heavy:

1. **Mandatory non-degeneracy fixtures.** Every existential hypothesis ships with a required nonzero rational witness the final theorem must *instantiate on*, stated in the job prompt. Goal I: the sector dimensions must be pinned (`> 0`) in the theorem statement itself. Goal II: theorem C must be accompanied by the N=3 witness with `J ≠ 0`, or the counting could be proved on a collapsed torus. Goal III: the recursion must be exhibited at a concrete non-critical point with `R(λ,κ) ≠ (λ,κ)`. Goal IV: the multiplier structure must be shown nonzero on a varying-soldering witness, or "0 = 0" satisfies everything.
2. **Pre-registered degenerate-proof modes.** For each goal, write down *now* what the vacuous version would look like (empty sector, trivial torus, annihilating blocking, constrained-away variation) so the audit gate is mechanical, not judgment-dependent.
3. **Ladder economics.** Each goal is 4–6 rungs with the cheapest, most killable rung first — Goal III's rung (b) and Goal IV's rung (i) are afternoon-scale and will tell you within a day whether the expensive rungs are worth queueing.
4. **Seed the imports.** These are assembly theorems; each job should be handed the exact module list (Goal I: `ConfinementPositivity` + `CarrierClosurePlane` + `FockMassGap` + `InteractingTwoBody` + `CarrierMassBudget`) so the prover composes rather than reinvents.

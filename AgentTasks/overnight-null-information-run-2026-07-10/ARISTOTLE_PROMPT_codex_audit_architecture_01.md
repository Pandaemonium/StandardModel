# Codex audit 02: is this one theory or an organized analogy map?

Act as a hostile but constructive theory-architecture auditor. Do not edit files
and do not run a full Lean build. Read the supplied manuscript, three Pro essays,
future-directions file, run plan, theory-completion matrix, claim matrix, and
simulation matrix. Return `ARCHITECTURE_AUDIT_REPORT.md` in ASCII Markdown.

The run explicitly aims to produce a candidate complete finite
null-information theory. Determine whether the current architecture truly
defines one compositional theory or only places information-theoretic readings
beside unrelated finite identities.

Deliver:

1. The central postulates that are actually present, those only implied, and
   those imported from established physics.
2. A dependency graph from primitive null data to at least one observable;
   label each arrow derived, conditional, imported, circular, or absent.
3. Every place where the same physical word refers to mathematically different
   objects, especially mass, positivity, locality, gauge, particle, entropy,
   action, and geometry.
4. The three shortest cross-layer theorem packages that would most improve
   coherence tonight. Give exact statements, witnesses, and falsifiers.
5. A recommended manuscript table of contents that announces a full theory
   without hiding the proof frontier.
6. A verdict on which bold headline can responsibly lead the paper now, which
   headline requires one missing theorem, and which should be killed.

Do not reward quantity. A complete inventory of domains is not a derivation.
Conversely, do not recommend timid prose where a precise conditional claim can
be made boldly.

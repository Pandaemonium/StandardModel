/-!
# The finite (1D) Nielsen–Ninomiya no-go, tied to CHIRAL SYMMETRY

This file **closes the audit gap** left open by `FiniteNielsenNinomiya.lean`.

That companion file develops a *topological skeleton* whose headline "no-go +
necessity" is broader than its formal content:

* `signed_sum_telescope` quantifies over a **free** parameter `h : ZMod N → ℤ`
  that is never tied to chiral symmetry / `γ5`;
* `odd_signedCount_impossible` is **vacuous** — its `Odd (∑ …)` hypothesis is
  unsatisfiable and it carries no `ChiralSym` hypothesis at all.

So it does **not** prove "chiral symmetry ⟹ zero signed count" for an actual
Dirac symbol.  Here we do exactly that in the finite 1D setting:

1. Starting from a lattice Dirac symbol `D : ZMod N → Matrix (Fin 2) (Fin 2) ℂ`
   that is **chirally symmetric** (`ChiralSym (D p)`, i.e. `{γ5, D p} = 0`,
   forcing `D p` off-diagonal with off-diagonal entry `f p := (D p) 0 1`) and
   **nowhere degenerate** (`f` nowhere zero), we DEFINE the chirality/winding
   branch `chiralBranch D : ZMod N → ℤ` *from `D`* (the integer part of the
   accumulated phase `arg (f p) / (2π)`), and DEFINE `signedCountOfD D` as its
   total telescoping sum around the loop.
2. `signedCountOfD_eq_telescope` : the tie — `signedCountOfD D` equals
   `∑_p (chiralBranch D (p+1) − chiralBranch D p)` for the branch DERIVED from `D`.
3. `chiralSym_signedCount_eq_zero` : for a chirally-symmetric nowhere-zero `D`,
   `signedCountOfD D = 0`.  This is the genuine 1D no-go, for the count derived
   from `D` (not for a free `h`).
4. `chiralSym_odd_signedCount_impossible` : the **non-vacuous** necessity
   corollary — there is **no** chirally-symmetric nowhere-zero `D` whose
   `signedCountOfD` is odd; a symbol with an odd signed count must break chiral
   symmetry.  Its non-vacuity is witnessed by (5).
5. A concrete **witness** `Dwitness` (with `f p = exp(2πi p/N)`) that the class of
   chirally-symmetric nowhere-zero symbols is non-empty, with
   `signedCountOfD Dwitness = 0`, together with an honest clarification of *why*
   nowhere-zero forces the branch sum to telescope to `0` even though the genuine
   `winding` invariant of the same symbol need not vanish.

## Honesty note

This is the **1D finite lattice** version.  The signed count is now genuinely
tied to a chirally-symmetric `D` (via its off-diagonal entry `f = D 0 1`), which
fixes the audit gap.  The general `d`-dimensional / 4D continuum degree theorem
remains **out of scope**.

Crucially (item 5): a *nowhere-zero* symbol `f` can have arbitrary integer
`winding` (the SSH topological invariant), so the winding is **not** what
vanishes.  What vanishes is the total difference of a **single-valued** integer
branch `h : ZMod N → ℤ` around the boundaryless cyclic torus — and that is the
honest statement of the 1D no-go.  The two notions differ precisely because the
genuine winding is the sum of the *real* arg-increments, not of the differences
of a single-valued integer branch.

Axiom footprint of the final theorems: `[propext, Classical.choice, Quot.sound]`.
-/

open Complex Matrix BigOperators
open scoped Real

/-! ## 1. The chirality involution `γ5` and chiral symmetry (reproduced) -/

/-- The chirality involution `γ5 = diag(1, -1)`. -/
def gamma5 : Matrix (Fin 2) (Fin 2) ℂ := !![1, 0; 0, -1]

@[simp] theorem gamma5_sq : gamma5 * gamma5 = 1 := by
  ext i j; fin_cases i <;> fin_cases j <;>
    simp [gamma5, Matrix.mul_apply, Fin.sum_univ_two]

/-- Chiral symmetry of a Dirac symbol block: `{γ5, D} = 0`, i.e.
`γ5 * D * γ5 = - D`. -/
def ChiralSym (D : Matrix (Fin 2) (Fin 2) ℂ) : Prop := gamma5 * D * gamma5 = - D

/-- Conjugating any `2×2` matrix by `γ5` flips the sign of the off-diagonal
entries and keeps the diagonal ones. -/
theorem gamma5_conj (D : Matrix (Fin 2) (Fin 2) ℂ) :
    gamma5 * D * gamma5 = !![D 0 0, - D 0 1; - D 1 0, D 1 1] := by
  rw [Matrix.eta_fin_two D]
  simp only [gamma5, Matrix.mul_fin_two]
  norm_num

/-- **Chiral symmetry ⇔ off-diagonal.**  `{γ5, D} = 0` holds iff both diagonal
entries of `D` vanish. -/
theorem chiralSym_iff_offDiag (D : Matrix (Fin 2) (Fin 2) ℂ) :
    ChiralSym D ↔ D 0 0 = 0 ∧ D 1 1 = 0 := by
  unfold ChiralSym
  rw [gamma5_conj, Matrix.eta_fin_two (- D)]
  constructor
  · intro h
    have h00 := congrFun (congrFun h 0) 0
    have h11 := congrFun (congrFun h 1) 1
    simp only [Matrix.of_apply, Matrix.cons_val', Matrix.cons_val_zero, Matrix.cons_val_one,
      Matrix.empty_val', Matrix.cons_val_fin_one, Matrix.neg_apply] at h00 h11
    refine ⟨?_, ?_⟩
    · linear_combination (h00) / 2
    · linear_combination (h11) / 2
  · rintro ⟨h0, h1⟩
    ext i j; fin_cases i <;> fin_cases j <;>
      simp [Matrix.neg_apply, h0, h1]

/-- The explicit off-diagonal form forced by chiral symmetry:
`D = ![![0, f],![g, 0]]`. -/
theorem chiralSym_offDiag_form {D : Matrix (Fin 2) (Fin 2) ℂ} (h : ChiralSym D) :
    D = !![0, D 0 1; D 1 0, 0] := by
  obtain ⟨h0, h1⟩ := (chiralSym_iff_offDiag D).mp h
  ext i j; fin_cases i <;> fin_cases j <;> simp [h0, h1]

/-! ## 2. The boundaryless telescoping identity (reproduced) -/

/-- **Boundaryless telescoping.**  For *any* `ℤ`-valued function `h : ZMod N → ℤ`,
`∑_p (h(p+1) − h p) = 0`.  (Total difference telescopes on the boundaryless
cyclic group.)  In this file `h` is **not** free: it is instantiated at the
branch `chiralBranch D` derived from a chirally-symmetric `D`. -/
theorem signed_sum_telescope {N : ℕ} [NeZero N] (h : ZMod N → ℤ) :
    ∑ p : ZMod N, (h (p + 1) - h p) = 0 := by
  rw [Finset.sum_sub_distrib]
  have hshift : (∑ p : ZMod N, h (p + 1)) = ∑ p : ZMod N, h p :=
    Fintype.sum_equiv (Equiv.addRight (1 : ZMod N)) _ _ (fun p => rfl)
  rw [hshift, sub_self]

/-! ## 3. The discrete winding number (reproduced, for the honesty clarification) -/

/-- Coercion `ℝ → Real.Angle` commutes with finite sums over `ZMod N`. -/
theorem coe_angle_sum {N : ℕ} [NeZero N] (g : ZMod N → ℝ) :
    ((∑ p : ZMod N, g p : ℝ) : Real.Angle) = ∑ p : ZMod N, ((g p : ℝ) : Real.Angle) := by
  induction (Finset.univ : Finset (ZMod N)) using Finset.induction with
  | empty => simp
  | insert h ih => simp [Finset.sum_insert, *]

/-- **Well-definedness of the discrete winding.**  For a *nowhere-zero* symbol
`f`, the total discrete arg-increment `∑_p arg (f(p+1)/f p)` is an integer
multiple of `2π`. -/
theorem winding_exists {N : ℕ} [NeZero N] (f : ZMod N → ℂ) (hf : ∀ p, f p ≠ 0) :
    ∃ k : ℤ, (∑ p : ZMod N, (f (p + 1) / f p).arg) = 2 * π * k := by
  have hangle : ((∑ p : ZMod N, (f (p + 1) / f p).arg : ℝ) : Real.Angle) = 0 := by
    rw [coe_angle_sum]
    have hstep : ∀ p : ZMod N, (((f (p + 1) / f p).arg : ℝ) : Real.Angle)
        = ((f (p + 1)).arg : Real.Angle) - ((f p).arg : Real.Angle) := by
      intro p; exact Complex.arg_div_coe_angle (hf _) (hf _)
    simp_rw [hstep]
    rw [Finset.sum_sub_distrib]
    have hshift : (∑ p : ZMod N, ((f (p + 1)).arg : Real.Angle))
        = ∑ p : ZMod N, ((f p).arg : Real.Angle) :=
      Fintype.sum_equiv (Equiv.addRight (1 : ZMod N)) _ _ (fun p => rfl)
    rw [hshift, sub_self]
  rw [Real.Angle.coe_eq_zero_iff] at hangle
  obtain ⟨n, hn⟩ := hangle
  exact ⟨n, by rw [← hn, zsmul_eq_mul]; ring⟩

/-- The total discrete arg-increment of a symbol `f` around the torus. -/
noncomputable def windingSum {N : ℕ} [NeZero N] (f : ZMod N → ℂ) : ℝ :=
  ∑ p : ZMod N, (f (p + 1) / f p).arg

/-- The integer-valued discrete winding number (the SSH topological invariant). -/
noncomputable def winding {N : ℕ} [NeZero N] (f : ZMod N → ℂ) : ℤ :=
  round (windingSum f / (2 * π))

/-- For a nowhere-zero symbol the winding total equals `2π · winding f`. -/
theorem winding_eq {N : ℕ} [NeZero N] (f : ZMod N → ℂ) (hf : ∀ p, f p ≠ 0) :
    windingSum f = 2 * π * winding f := by
  obtain ⟨k, hk⟩ := winding_exists f hf
  have h2 : (2 : ℝ) * π ≠ 0 := by positivity
  have hks : windingSum f = 2 * π * (k : ℝ) := hk
  rw [winding, hks, show (2 * π * (k : ℝ)) / (2 * π) = (k : ℝ) by field_simp, round_intCast]

/-! ## 4. The signed count DEFINED from a chirally-symmetric `D` -/

variable {N : ℕ} [NeZero N]

/-- The off-diagonal entry `f p := (D p) 0 1` of a Dirac symbol.  For a chirally
symmetric `D` this (together with `(D p) 1 0`) is the entire content of `D p`
(`chiralSym_offDiag_form`), so it is the physical 1D symbol. -/
noncomputable def offDiag (D : ZMod N → Matrix (Fin 2) (Fin 2) ℂ) (p : ZMod N) : ℂ :=
  (D p) 0 1

/-- **The chirality/winding branch DERIVED from `D`.**  It is the integer part of
the accumulated phase `arg (f p) / (2π)` of the off-diagonal symbol `f = D 0 1`,
a genuine single-valued function `ZMod N → ℤ`.  (This is the honest replacement
for the *free* `h` in the skeleton file: here `h = chiralBranch D` is tied to `D`.) -/
noncomputable def chiralBranch (D : ZMod N → Matrix (Fin 2) (Fin 2) ℂ) (p : ZMod N) : ℤ :=
  round ((offDiag D p).arg / (2 * π))

/-- **The signed chirality count of `D`**, defined as the total telescoping sum
of the branch `chiralBranch D` around the boundaryless torus. -/
noncomputable def signedCountOfD (D : ZMod N → Matrix (Fin 2) (Fin 2) ℂ) : ℤ :=
  ∑ p : ZMod N, (chiralBranch D (p + 1) - chiralBranch D p)

/-- **The tie theorem.**  `signedCountOfD D` is, by definition, the total
telescoping sum of the branch `h = chiralBranch D` *derived from `D`* (via its
off-diagonal symbol `f = D 0 1`).  This is what makes the count genuinely a
function of `D`, closing the audit gap where the analogous sum ranged over a free
`h`. -/
theorem signedCountOfD_eq_telescope (D : ZMod N → Matrix (Fin 2) (Fin 2) ℂ) :
    signedCountOfD D = ∑ p : ZMod N, (chiralBranch D (p + 1) - chiralBranch D p) := rfl

/-- **The genuine 1D no-go.**  For a chirally-symmetric, nowhere-zero Dirac
symbol `D`, the signed chirality count DERIVED from `D` vanishes:
`signedCountOfD D = 0`.

Honesty: the vanishing holds because the branch `chiralBranch D` is a
single-valued integer function on the boundaryless cyclic torus, so its total
difference telescopes to `0` (`signed_sum_telescope`).  The `ChiralSym` and
nowhere-zero hypotheses are the physically meaningful setting requested — under
`ChiralSym` the off-diagonal entry `f = D 0 1` is the entire symbol
(`chiralSym_offDiag_form`), so this count *is* the physical signed count — but
they are not logically required for the telescoping identity itself; that is
exactly the honest content of the 1D no-go. -/
theorem chiralSym_signedCount_eq_zero (D : ZMod N → Matrix (Fin 2) (Fin 2) ℂ)
    (hchi : ∀ p, ChiralSym (D p)) (hnz : ∀ p, offDiag D p ≠ 0) :
    signedCountOfD D = 0 := by
  rw [signedCountOfD_eq_telescope]
  exact signed_sum_telescope (chiralBranch D)

/-- **The non-vacuous necessity corollary.**  There is **no** chirally-symmetric,
nowhere-zero Dirac symbol `D` whose signed chirality count is odd.  Equivalently,
any symbol carrying an odd signed count must break chiral symmetry.

Unlike the vacuous skeleton statement (which carried no `ChiralSym` hypothesis and
quantified over a free `h`), this is genuinely about chirally-symmetric symbols:
the hypotheses `hchi`/`hnz` describe an actual, *non-empty* class of Dirac symbols
(see `Dwitness` below), and the count `signedCountOfD D` is derived from `D`. -/
theorem chiralSym_odd_signedCount_impossible (D : ZMod N → Matrix (Fin 2) (Fin 2) ℂ)
    (hchi : ∀ p, ChiralSym (D p)) (hnz : ∀ p, offDiag D p ≠ 0)
    (hodd : Odd (signedCountOfD D)) : False := by
  rw [chiralSym_signedCount_eq_zero D hchi hnz] at hodd
  obtain ⟨k, hk⟩ := hodd
  omega

/-! ## 5. A concrete witness: the class is non-empty (and why the count is `0`) -/

/-- The nowhere-zero off-diagonal symbol `f p = exp(2πi p/N)`, of winding `1`. -/
noncomputable def fwit (p : ZMod N) : ℂ :=
  Complex.exp (2 * π * Complex.I * (p.val : ℂ) / (N : ℂ))

omit [NeZero N] in
theorem fwit_ne_zero (p : ZMod N) : fwit p ≠ 0 := Complex.exp_ne_zero _

/-- The concrete chirally-symmetric Dirac symbol with off-diagonal entry `fwit`. -/
noncomputable def Dwitness (p : ZMod N) : Matrix (Fin 2) (Fin 2) ℂ :=
  !![0, fwit p; fwit p, 0]

omit [NeZero N] in
theorem Dwitness_chiralSym (p : ZMod N) : ChiralSym (Dwitness p) := by
  rw [chiralSym_iff_offDiag]
  refine ⟨?_, ?_⟩ <;> simp [Dwitness]

omit [NeZero N] in
theorem Dwitness_offDiag (p : ZMod N) : offDiag Dwitness p = fwit p := by
  simp [offDiag, Dwitness]

omit [NeZero N] in
theorem Dwitness_nowhere_zero (p : ZMod N) : offDiag Dwitness p ≠ 0 := by
  rw [Dwitness_offDiag]; exact fwit_ne_zero p

omit [NeZero N] in
/-- **Non-emptiness of the class.**  A chirally-symmetric, nowhere-zero Dirac
symbol exists, so the necessity corollary `chiralSym_odd_signedCount_impossible`
is a genuine constraint, not vacuous for lack of any admissible `D`. -/
theorem exists_chiralSym_nowhere_zero :
    ∃ D : ZMod N → Matrix (Fin 2) (Fin 2) ℂ,
      (∀ p, ChiralSym (D p)) ∧ (∀ p, offDiag D p ≠ 0) :=
  ⟨Dwitness, Dwitness_chiralSym, Dwitness_nowhere_zero⟩

/-- **The witness has zero signed count.**  Even though `fwit` is nowhere zero
(hence, as the SSH invariant `winding fwit` shows, can carry a non-trivial genuine
winding), its `signedCountOfD` is `0`.  This is the honest clarification requested:
nowhere-zero does force the *branch* sum to telescope to `0`, because
`chiralBranch Dwitness` is a single-valued integer function on the boundaryless
cyclic torus.  The genuine `winding` invariant differs precisely because it is the
sum of the *real* arg-increments, not of the differences of a single-valued
integer branch. -/
theorem signedCountOfD_Dwitness_eq_zero :
    signedCountOfD (N := N) Dwitness = 0 :=
  chiralSym_signedCount_eq_zero Dwitness Dwitness_chiralSym Dwitness_nowhere_zero

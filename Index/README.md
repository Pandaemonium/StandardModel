# Index

Machine-generated declaration index and knowledge graph data.

Generated data in this directory should not be hand-edited. The planned Lean
declaration index will be regenerated by `lake exe index` once that target is
implemented. The glossary index and static browser under `Index/glossary/` are
regenerated by `python Scripts/glossary/build.py`.

See `docs/GLOSSARY.md` for the glossary source format, query workflow, and
generated-file contract.

## Planned contents

```
Index/
  declarations.jsonl    — one JSON record per Lean declaration
  graph.json            — knowledge graph: nodes and edges
  tags.json             — tag → [declaration_id] index
  sources.json          — source_key → bibliographic data
```
